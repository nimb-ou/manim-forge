# Manim Forge

Turn a plain-English request into a 3Blue1Brown-style mathematical animation,
using a model fine-tuned on a corpus where **every example is proven to
render**.

Free, non-commercial, and built in the open — including the parts that went
wrong. See [`docs/POSTMORTEM.md`](docs/POSTMORTEM.md).

---

## The one idea

Public Manim datasets are text that was never executed. Scraped Manim code
spans six years of mutually incompatible API versions, so a model trained on
it learns a plausible-looking dialect that does not run.

Manim Forge render-gates everything. A row enters the corpus only after it has
been executed, rendered to video, and sampled to frames. It needs no
per-row human judgement, and the same component does three jobs — which is
what stops this project tripling in size:

| | the harness is… |
|---|---|
| the corpus | the data filter |
| evaluation | Render Success Rate *is* its pass rate |
| the product | the self-repair loop around the model |

## The open problem

Two measurements from opposite ends agree, and they are the reason the plan
looks the way it does.

Asked for a sixteen-*minute* explainer, the model returns sixteen *seconds* —
a 1.76% length ratio, flat across 81 tasks. It is not getting the subject
wrong; it is answering a much smaller question.

Measuring the corpus against the hand-written gold scenes says why:

| | corpus | gold |
|---|---|---|
| mean `self.play()` calls | 10.6 | 17.8 |
| uses `ValueTracker` | **1.3%** | 9.1% |
| uses `always_redraw` | **0.9%** | 9.1% |
| asserts its own numbers | 2.7% | 95.5% |

`ValueTracker` and `always_redraw` are what make an animation continuous
rather than a slideshow, and they are effectively absent. The render gate
filters for **executes**. Nothing yet filters for **animates**, and nothing
filters for **explains**. That is the whole of Phase 2.

## Layout

```
forge/
  harness/      render + error classification — the load-bearing component
  ingest/       5 public sources -> one schema, AST-structural dedupe
  gate/         execute everything, keep what survives
  repair/       lint + API introspection + an escalating repair loop
  retrieve/     few-shot retrieval over verified scenes
  synth/        teacher generation, provider rotation, task types
  primitives/   11 modules — the animation computes its own claims
  gold/         44 hand-authored scenes + the 61-scene curriculum
  evaluate/     benchmark, hard eval, visual critic
  orchestrator  job model: health is progress, never existence
  doctor.py     re-derive every number and diff it
```

The gold scenes are the style anchor, and they are written to a rule: **the
animation computes its own claims.** A scene about Kepler's second law
measures the swept areas rather than asserting they match; 42 of the 44
contain `assert` statements tying spoken numbers to computed ones. Three
narration errors were caught that way, and one scene had to be rewritten when
the check revealed I had invented its "honest attempts".

## Setup

```bash
brew install cairo pango pkg-config ffmpeg
brew install --cask basictex          # required: MathTex hard-fails without it
python3 -m venv .venv && ./.venv/bin/pip install -r requirements.txt
export PATH="/Library/TeX/texbin:$PATH"
```

```bash
./.venv/bin/python -m pytest          # 44 tests
./.venv/bin/python -m forge.doctor    # invariants + figures
./.venv/bin/python -m forge.gold.curriculum   # what to build next
```

The corpus is not in git — it is large, and it mixes sources whose terms are
stated with sources whose terms are not. It lives in a private Hugging Face
dataset; `scripts/backup_to_hf.py --restore` pulls it down.

## ManimCE, not ManimGL

Grant Sanderson's own code uses **ManimGL**. Everything else — the docs, the
datasets, every published result — uses **ManimCE**. They share a name and
little else.

This builds on **ManimCE 0.21.0** and treats `3b1b/videos` as *style
reference*, never as code to imitate. Mixing the two APIs in one training set
teaches a model to hallucinate across both, so corpus rows are tagged `ce` or
`gl` at ingest and can never blend silently.
